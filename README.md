## 📖 About The Project

**Kuna Clone Website** is my very first hands-on web development project. The primary goal of this project was to understand how modern websites are structured, styled, and brought to life from scratch. 

By building this clone, I practiced translating a visual concept into clean, working code while learning fundamental web development concepts and version control with Git.
